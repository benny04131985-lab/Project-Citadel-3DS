# Controls and presentation

Confirmed S3 behavior:

- **C-stick:** calibrated freelook.
- **START:** game pause/escape behavior.
- **SELECT:** manual Legacy/Dual-screen layout toggle during gameplay.
- **Touchscreen:** native interface interaction.
- **3D slider:** controls stereoscopic world depth.

The normal station world uses true stereoscopic geometry. HUD, weapon, cursor,
text, borders, menus, cyberspace, 360-degree view, and full security-camera
takeover remain flat for visual stability.
