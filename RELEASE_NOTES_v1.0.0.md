# Project Citadel 3D v1.0.0 — S3 Ship

## Highlights

- True dual-camera stereoscopic rendering for ordinary station gameplay.
- Centered 3D-slider response with a five-pixel maximum convergence ceiling.
- Flat zero-parallax HUD, weapon, cursor, text, and interface.
- Frame-time-normalized C-stick freelook while stereo is active.
- Stable entry into and exit from cyberspace.
- Flat fallback for cyberspace, 360-degree view, and full security-camera
  takeover.
- Independent `SystemShock3D` SD-card runtime path.

## Comfort note

The middle of the physical 3D slider is the recommended sweet spot. The
highest setting remains available, but comfort is player- and session-specific.

## Known issue

HOME/suspend remains somewhat inconsistent and is deferred to a future
lifecycle hotfix.

## Game data

No copyrighted game data is included. A legally obtained original copy of
System Shock is required.
